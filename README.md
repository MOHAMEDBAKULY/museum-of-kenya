# Nairobi National Museum · a 3D walk

An immersive, browser-based tour of the **Nairobi National Museum** on Museum Hill, Nairobi. Start on the forecourt, walk through the Hall of Kenya and into every permanent gallery, then out to Ahmed's courtyard, the Snake Park and the Botanic Gardens.

Built with Vite, React, TypeScript, Three.js (react-three-fiber and drei), Tailwind CSS and `@react-three/postprocessing`.

## Run it

```bash
npm install
npm run dev        # http://localhost:4317
```

The full project, including photographs and the 14 rooms, is in the working tree that could not be pushed from this environment: `gh` is not logged in here, so `git push` to github.com has no credentials. Photographs and other binary assets cannot be written through the text file API without corrupting them.

Open daily 8:30 am – 5:30 pm. Photographs © National Museums of Kenya (museums.or.ke).
